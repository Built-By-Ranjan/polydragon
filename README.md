# POLY ARENA — Bot vs Dragon

Single-player low-poly FPS. Pure static site (HTML + JS), no server or build step.

## Deploy on Netlify
Drag this whole folder onto https://app.netlify.com/drop  (or connect it via Git; publish directory is ".").

## Run locally
    python3 -m http.server 3000
    # open http://localhost:3000

Controls: WASD move · Shift sprint · Space jump · LMB shoot · RMB scope · 1/2 or scroll weapon · TAB scoreboard · Esc pause.

Based on bhittu21/polygame (MIT).
